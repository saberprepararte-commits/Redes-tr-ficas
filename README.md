# Simulador realista de red trófica - V11 bilingüe

Versión con botón de idioma **English / Español**.

## Incluye
- Grupo control estable.
- Cambio de idioma en textos principales, controles, métricas, especies, preguntas y mensajes.
- Intervenciones: herbívoros, peces pequeños, garzas y caimán.
- Variables ambientales: radiación solar, agua, contaminación y nutrientes.

## Publicar en GitHub Pages
Sube `index.html` a la raíz del repositorio y activa GitHub Pages desde Settings > Pages.
